# Mneme

SillyTavern 记忆插件：卷宗式记忆、羁绊、道具与折叠剧情线。支持副 API 独立总结、多套命名提示词配置，以及把摘要注入按聊天隔离的世界书。

## 安装

### 方式一：Git URL（推荐）

酒馆 → 扩展 → 安装扩展，填入：

```
https://github.com/ShanTing-sy/Mneme
```

安装后刷新页面。以后可以在「扩展」里点更新。

### 方式二：手动复制

1. 把 `manifest.json` 与 `dist/` 复制到 `SillyTavern/data/<用户名>/extensions/Mneme/`
2. 刷新酒馆页面
3. 魔法棒菜单中点击 `Mneme`

本机一键安装：

```bash
npm run build
node scripts/install.mjs
```

## 使用

- 每轮 AI 回复后自动生成一条摘要，满 10 条封卷。
- 「羁绊」「道具」由模型顺带上报，也可手动编辑。
- 「剧情线」默认关闭，可在设置中开启新聊天自动生成。
- 模型输出的记忆块会以 HTML 注释形式附在回复末尾，插件解析后收进账本。
- 记忆块只从「发给模型的内容」里剔除；聊天记录本身不删除、不改写。
- 设置里的「发送给模型的最新轮数」只减少发给模型的原始对话，不会隐藏聊天楼层。

### 副 API

右上角 `⇄` 按钮管理副 API。可以保存多条：

- 酒馆「连接配置管理」里的配置（沿用其模型与密钥）
- 自定义 OpenAI 兼容端点（基础 URL、密钥选填、模型名、获取模型、连接测试）

每条副 API 可单独绑定提示词，并设置温度、top_p、最大输出、超时与重试次数。
切换「摘要生成来源」为主模型或副 API；副 API 同时接管摘要与初始羁绊 / 剧情线解析。

### 提示词配置

底部「提示词」标签页存放多份命名配置。每份配置包含提示词、摘要与卷宗参数、
导演视野、自动解析开关、外观与悬浮球样式。

- 点击配置只切换提示词。
- 「默认」配置可展开查看内置默认提示词，只读不可修改。
- 「修改」展开编辑；「保存」写回配置；「另存为新配置」复制一份。
- 「读取当前设置」会把当前生效的提示词（包括内置默认）与设置值填入编辑器。
- 「应用设置」才会把该配置的记忆与外观快照写入当前全局值。
- 不包含面板位置、尺寸、悬浮球位置与显隐，避免切换配置时打乱布局。

### 世界书注入

设置 → 记忆注入，可选择「扩展提示词」（默认）或「世界书」。

世界书模式会按「当前聊天 + 角色」创建 `Mneme·角色·聊天` 世界书，并绑定为聊天世界书。
条目包括记录要求、长期记忆、短期记忆（常驻），以及重要记忆、永久记忆、
永久物品、角色印象（关键词触发）。短期记忆满卷后自动总结成复盘并追加到长期记忆。

当前聊天已有其他世界书时不会自动替换；可在设置里点「替换绑定」。
世界书写入失败会自动退回扩展提示词。

## 开发

```bash
npm install
npm test
npm run build
npm run typecheck
```

集成验收（零依赖 CDP，需要本机 Edge）：

```bash
node scripts/verify-cdp.mjs    # 独立测试页，验证整条记忆链路
node scripts/verify-live.mjs   # 真实酒馆页面，验证扩展加载与面板
```

## 数据

所有记忆保存在当前聊天的元数据 `chat_metadata.mneme` 中，随聊天导出。

世界书模式下会额外写入一本按聊天命名的世界书；它是记忆的投影，源数据仍是
`chat_metadata.mneme`。配置与副 API（含密钥）保存在酒馆扩展设置 `settings.json`
中，仅本机使用。
