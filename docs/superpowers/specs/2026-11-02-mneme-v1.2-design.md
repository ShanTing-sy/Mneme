# Mneme V1.2.0 设计稿

日期：2026-11-02
状态：已实施
版本：1.2.0

## 目标

在 V1.1.1 的基础上增加三块能力：

1. 多条「副 API」管理，可切换接管摘要与初始解析。
2. 底部居中的「提示词」标签页，用命名配置保存提示词与相关设置快照。
3. 摘要可注入按「当前聊天 + 角色」隔离的世界书。

## 一、数据模型

### 副 API

```ts
interface SecondaryApiParams {
  temperature: number; // 0–2
  topP: number;        // 0–1
  maxTokens: number;   // 64–8192
  timeoutMs: number;   // 5000–300000
  retries: number;     // 0–5
}

interface SecondaryApiConfig {
  id: string;
  name: string;
  enabled: boolean;
  source: 'profile' | 'custom';
  profileId: string;
  baseUrl: string;
  apiKey: string;
  model: string;
  availableModels: string[];
  promptId: string | null;
  params: SecondaryApiParams;
}
```

- `profile`：走酒馆 `ConnectionManagerRequestService.sendRequest`，沿用连接配置的模型与密钥。
- `custom`：直接请求 `${baseUrl}/chat/completions`，可选 `Authorization: Bearer`。
- 密钥保存在扩展设置 `settings.json`，面板明确提示仅本机使用。

### 提示词配置

```ts
interface SummaryPreset {
  id: string;
  name: string;
  prompt: string; // 空 = 内置默认
  memory: {
    volumeSize: number;
    tokenBudget: number;
    majorRetentionVolumes: number;
    keepRecentTurns: number;
    directorView: 'current' | 'current-next' | 'volume' | 'full';
    autoInitBonds: boolean;
    autoTimeline: boolean;
  };
  appearance: {
    theme: 'auto' | 'light' | 'dark';
    accent: string;
    fontSize: number;
    ballText: string;
    ballImage: string;
    ballSize: number;
    ballOpacity: number;
    ballBgTransparent: boolean;
    ballBg: string;
    ballBorder: boolean;
    ballBorderColor: string;
    ballColor: string;
    ballHalfHide: boolean;
  };
}
```

设置字段：

```ts
summaryPresets: SummaryPreset[];
activePresetId: string | null;
aiSource: 'main' | 'secondary';
activeSecondaryApiId: string | null;
secondaryApis: SecondaryApiConfig[];
injectionMode: 'prompt' | 'worldbook';
worldbookPrefix: string;
```

`settingsVersion` 升到 2。旧的 `summaryPrompt` 非空时迁移成 id 为 `legacy` 的配置；
旧字段保留以兼容降级。迁移完成后「默认」配置使用内置默认提示词，不再被旧字段劫持。

## 二、副 API 调用

- 顶部 `⇄` 按钮（关机按钮右侧）打开副 API 子面板。
- `摘要生成来源`：主模型 / 副 API，同时控制摘要与初始羁绊 / 剧情线解析。
- 主模型路径：沿用注入记录要求 + 正文末尾 MNEME 块。
- **聊天记录永远不改写**：记忆块保留在聊天消息里；只在 `GENERATE_AFTER_DATA`
  构造发给模型的提示词时剔除。`keepRecentTurns` 也只裁剪提示词，不隐藏聊天楼层。
- 副 API 路径：
  1. 消息里已有合法 MNEME 块 → 直接使用，不额外调用。
  2. 否则入队串行总结：system = 记忆记录助手前言 + 记录要求；user = 最近 10 条对话（单条 2000 字、总 12000 字）+ 当前卷记录 + 最近 3 卷复盘 + 任务。
  3. 解析失败时按原文存一条 `source: 'raw'` 的记录并亮提示点。
- 队列在切聊天或停止生成时中止；落账前重新校验消息仍存在且未被编辑。
- 没有可用副 API 时退回主模型写记录要求，避免记忆静默丢失。
- 初始解析在副 API 模式下使用同一套调用，`maxTokens = max(1200, 配置值)`。

## 三、提示词配置标签页

- 底部标签改为 5 个：记忆 / 羁绊 / 提示词 / 道具 / 剧情线，提示词在正中间。
- 每个配置默认折叠，只显示名称与一行摘要；点「修改」才展开编辑。
- 「默认」配置可展开查看内置默认提示词，**只读不可修改**。
- 操作：保存、另存为新配置、读取当前设置、应用设置、删除。
- 「读取当前设置」同时填入当前生效的提示词（包括内置默认），方便直接把默认文本存成自定义配置。
- **切换配置只换提示词**；配置内的设置是快照，必须点「应用设置」才写入全局。
- 应用设置只写 `memory + appearance`，不碰面板位置、尺寸、悬浮球位置与显隐。
- 副 API 的「绑定提示词」只绑定配置的 `prompt` 文本；配置里的设置对它无效。
- 解析优先级：
  - 主模型：当前配置 prompt → 内置默认。
  - 副 API：API 绑定配置 prompt → 当前配置 prompt → 内置默认。
  - 任何一级为空都落回内置默认。

## 四、世界书注入

- 设置 → 记忆注入：扩展提示词（默认）/ 世界书。
- 世界书名：`Mneme·{角色名}·{聊天文件名}`，非法文件名字符替换为 `-`。
- 绑定方式：`chat_metadata.world_info = 书名`，并 `saveMetadata()`。
- 同名书属于其它聊天时自动追加 `·2`～`·5`；仍冲突则报错，不覆盖。
- 当前聊天已有其它世界书时不自动替换；面板显示冲突与「替换绑定」按钮。
- 条目：

| 条目 | 内容 | 常驻 | 关键词 |
| --- | --- | --- | --- |
| `Mneme·记录要求` | 提示词 + 动态卷信息（仅主模型摘要路径） | 是 | — |
| `Mneme·长期记忆` | 所有已封卷复盘 | 是 | — |
| `Mneme·短期记忆` | 当前卷普通记忆（重要/永久单独成条） | 是 | — |
| `Mneme·重要记忆` | 当前 + 保留卷内的重要记忆 | 否 | 人物/地点/锚点 |
| `Mneme·永久记忆` | 全部永久记忆 | 否 | 人物/地点/锚点 |
| `Mneme·永久物品` | 状态为「持有」的道具 | 否 | 道具名 |
| `Mneme·角色印象` | 好感/等级/印象 + 最近一次变化 | 否 | 角色名 |

- 空内容条目不新建；已有条目 `disable: true`，不删除。
- 写世界书用 `saveWorldInfo(name, data, true)` 立即落盘；600ms 防抖，已有排队时不重置计时器。
- 切回提示词 / 休眠 / 切聊天时：只处理含 `Mneme·` 托管条目的书，禁用条目并解绑；用户自己的世界书不动。
- 写入失败或绑定冲突时回退扩展提示词，并显示错误，避免记忆断档。

## 五、错误处理

- `panelState` 增加：`showApis`、`summaryRunning`、`summaryStage`、`summaryError`、`summaryQueue`、`apiTestStatus`、`worldbookReady/Active/Book/Bound/Conflict/Error`。
- 副 API 错误：面板红字 + 提示点；日志中密钥打码。
- 世界书错误：设置页红字 + 扩展提示词兜底。
- 插件休眠：中止总结队列、清空扩展提示词、禁用 Mneme 世界书条目。
- 正文保护：聊天消息不做任何改写。记忆块只在 `stripPromptDeltas` 里从
  「发给模型的提示词」中剔除；fenced JSON 兜底逐块匹配，禁止跨块。
  `stripDeltaSafely` 保留为工具函数与护栏测试，不再用于改写聊天。
- 指纹统一按「去掉记忆块后的正文」计算，保证聊天里保留块时 `reconcile` 仍能匹配。

## 七、默认决定

1. 「永久物品」= 当前状态为「持有」的道具；丢失/消耗的不写入。
2. 副 API 密钥保存在酒馆扩展设置 `settings.json` 明文，仅本机使用；不接酒馆密钥库。
3. 自定义端点直接由浏览器请求；跨域由端点侧放行，或改用酒馆连接配置。
